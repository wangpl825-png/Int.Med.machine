# 內科練功坊 · Internal Medicine Practice Machine

給內科住院醫師的互動式刷題系統。以歷屆考題、教科書題目或自訂題庫進行刻意練習 (deliberate practice)，
支援 **醫學影像判讀（EKG / CXR / CT / 病理 / 皮膚）** 與 **全螢幕縮放燈箱**。

- **單一檔案**：整個應用程式就是 `index.html`，沒有後端、沒有建置流程、沒有相依套件安裝。
- **完全在瀏覽器端執行**：題庫、錯題本、學習紀錄都存在你自己的 `localStorage`，不會上傳到任何伺服器。
- **離線可用**：Tailwind CDN 連不上時，內建的 CSS 設計系統仍能維持完整版面與可讀性。

## 快速開始

### 方式一：直接打開
下載 `index.html`，用瀏覽器打開即可（雙擊、或拖進 Chrome / Safari / Edge）。

### 方式二：GitHub Pages
1. 把本 repo 推上 GitHub。
2. `Settings → Pages → Source` 選擇 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`。
3. 幾分鐘後即可用 `https://<帳號>.github.io/<repo>/` 開啟。

### 方式三：Vercel / Netlify
直接匯入 repo，Framework 選 **Other**、Build command 留空、Output directory 填 `.` 即可。

首次開啟會自動載入內建範例題庫（23 題，含 5 題影像題），可立即試用。

## 三大功能區

| 模式 | 用途 | 說明 |
|---|---|---|
| **A · 完整測驗** | 整份歷屆考題 / 章節測驗 | 預設載入題庫全部題目（歷屆卷通常 ~80 題）。可選科別範圍、是否打亂題序、作答時限（60/90/120/180 分鐘）。全部作答後一次交卷，再顯示分數與逐題詳解。 |
| **B · 零碎時間練習** | 值班空檔、通勤 | 題數選 5 / 10 / 20 / 50 / 100（或用滑桿微調、或選「全部」），並可複選次專科。作答完成後統一交卷檢討。 |
| **C · 錯題重測** | 攻克弱點 | A、B 模式中**答錯或未作答**的題目自動收錄。可依科別與題數重測；答對達設定次數（預設 1 次，可在「使用說明」中改為 2 或 3 次）後自動移出錯題本。 |

另有 **題庫管理**（匯入 / 匯出 / 分科統計）與 **學習紀錄**（歷次成績、分科強弱排序）。

## 詳解卡片結構

交卷後每一題都會產生一張檢討卡：

1. **狀態標頭**：答對 ✓ / 答錯 ✗ / 未作答 ⊘，含題號、科別、難度。
2. **題幹、圖片與選項**：同時標示「你的選擇」與「正解」。
3. **可展開／收合的詳解手風琴**：
   - **核心解析 (Core Concept / Pearl)**：為什麼正解是對的。
   - **選項逐項解析與修正**：每個選項逐一說明；錯誤選項除了說明錯在哪裡，還會用橘色區塊標出
     **「如何修正才會正確」**——即題幹或選項要怎麼改寫，這個選項才會變成正解。

> 撰寫題目時，只要在 `option_breakdown` 的文字中寫「**修正：**⋯」，系統會自動把它拆出來獨立成橘色修正區塊。

## JSON 題庫格式

最外層是題目物件的**陣列**（也接受 `{"questions": [...]}`）。

```json
[
  {
    "id": "Q001",
    "category": "心臟內科 (Cardiology)",
    "difficulty": "中",
    "tags": ["ACS", "STEMI"],
    "stem": "一名 65 歲男性因突發性胸痛至急診，心電圖 (EKG) 檢查如圖所示。下列處置何者最合適？",
    "image_url": "https://example.com/ekg_stemi.jpg",
    "image_caption": "V1-V4 ST 節段上升",
    "options": [
      "A. 安排緊急冠狀動脈攝影 (Emergency Coronary Angiography)",
      "B. 給予靜脈注射類固醇 (IV Steroids)",
      "C. 診斷為急性心包膜炎，給予 NSAID 治療",
      "D. 觀察 24 小時後再追蹤 Cardiac Enzymes"
    ],
    "answer": "A",
    "core_explanation": "EKG 顯示 V1-V4 ST 節段上升，符合前壁急性心肌梗塞 (Anterior STEMI)，首選處置為緊急 PCI。",
    "option_breakdown": {
      "A": "正確。符合 STEMI 臨床指引，應在 90 分鐘內執行 Primary PCI。",
      "B": "錯誤。類固醇對 STEMI 無治療效果。修正：若題幹改為「心包膜炎併發嚴重發炎反應」，才可能考慮抗發炎治療。",
      "C": "錯誤。EKG 為區域性 ST 上升非廣泛性。修正：若心電圖改為廣泛導程凹面向上 ST 上升併 PR 節段下降，則此選項正確。",
      "D": "錯誤。STEMI 屬醫療急症，延誤再灌流時間會增加死亡率。修正：若病人為心肌酵素陰性之低風險胸痛，則觀察並連續追蹤才恰當。"
    }
  }
]
```

### 欄位說明

| 欄位 | 必填 | 說明 |
|---|---|---|
| `id` | 建議 | 題號。用於錯題本比對與匯入去重；未填時自動編號。 |
| `category` | 建議 | 次專科字串。決定篩選器與分科統計，格式自訂（`心臟內科 (Cardiology)` 或 `Cardiology (心臟內科)` 皆可）。 |
| `stem` | ✅ | 題幹，支援換行。 |
| `image_url` | 選填 | 圖片網址、`data:` URI，或內建示意圖 `builtin:*`。多張圖可改用 `images: [...]`。也接受 Markdown 連結寫法 `[url](url)`，會自動還原。 |
| `image_caption` | 選填 | 圖片說明，顯示於圖片下方與燈箱。 |
| `options` | ✅ | 陣列 `["A. ⋯","B. ⋯"]`（有無 `A.` 前綴皆可）或物件 `{"A":"⋯"}`。 |
| `answer` | ✅ | 正解字母 `"A"`；複選用 `["A","C"]` 或 `"AC"`；也接受索引數字或完整選項文字。 |
| `core_explanation` | 建議 | 核心解析 / Pearl。 |
| `option_breakdown` | 建議 | 逐項解析物件。文字中的「修正：⋯」會自動抽出成橘色修正區塊。 |
| `option_fix` | 選填 | 若想把修正建議與錯誤說明分開存放，可用此物件 `{"B":"若題幹改為⋯"}`。 |
| `difficulty` / `tags` / `source` / `reference` | 選填 | 難度、標籤、出處、參考文獻，顯示於題目與詳解卡。 |

匯入時格式寬鬆：無法解析的題目會被略過，並列出原因，其餘題目照常匯入。

### 內建示意圖（離線可用）

`image_url` 填入下列值即可使用程式即時產生的 SVG 示意圖，方便在沒有圖檔時先建題：

| 值 | 內容 |
|---|---|
| `builtin:ekg-stemi` | ST 節段上升（凸面向上） |
| `builtin:ekg-hyperk` | 高聳窄基底 T 波、P 波變平 |
| `builtin:ekg-afib` | R-R 間期絕對不規則、無 P 波 |
| `builtin:cxr-pneumothorax` | 右側張力性氣胸胸部 X 光示意 |
| `builtin:derm-target` | 標靶樣皮膚病灶 |

> 這些皆為**教學示意圖 (schematic)**，並非真實病人影像，圖上均已標註。

## 匯入題庫的三種方式

1. **上傳 JSON 檔**：題庫管理 → 上傳 JSON 檔案（可一次多選）。
2. **貼上 JSON**：題庫管理 → 直接把內容貼進文字框 → 「匯入貼上的內容」。
3. **內建範例**：一鍵載入 `data/` 目錄中的兩份示範題庫。

匯入模式可選 **附加**（自動略過 `id` 與題幹重複者）或 **取代**。

## 影像與操作

- 點題目圖片開啟**全螢幕燈箱**。
- 支援：**雙指縮放 (pinch)**、拖曳平移、滑鼠滾輪縮放、**雙擊放大**、`+` / `-` / `0` 鍵、`Esc` 關閉。
- 寬幅影像（如心電圖長條）開啟時會自動放大到合適倍率，方便在手機上判讀細微波形。

### 鍵盤快速鍵（作答中）

| 按鍵 | 功能 |
|---|---|
| `A`–`E` 或 `1`–`5` | 選擇選項 |
| `←` `→` | 上一題 / 下一題 |
| `Enter` | 下一題 |
| `F` | 標記本題 |
| `Esc` | 關閉燈箱 / 對話框 |

## 資料保存

所有資料存在**這台裝置這個瀏覽器**的 `localStorage`：

| 內容 | 說明 |
|---|---|
| 題庫 | 重新開啟仍在 |
| 錯題本 | 跨測驗累積 |
| 學習紀錄 | 最近 100 次測驗 |
| 未完成的測驗 | 中途離開可從首頁「繼續作答」 |

> 換裝置、換瀏覽器或清除瀏覽資料會遺失。重要題庫請用「題庫管理 → 匯出 JSON」備份。

## 檔案結構

```
index.html                          單一檔案應用程式（含內建範例題庫）
data/
  sample-internal-medicine.json     內科綜合示範卷 18 題（CV / Chest / Nephro / GI / Endo / ID / Hema-Onco / Rheum）
  sample-image-cases.json           影像判讀示範 5 題（EKG × 3、CXR、Derm）
README.md
```

`data/` 內的 JSON 同時是**可直接上傳測試的範例檔**，也是撰寫自己題庫時的參考範本。
